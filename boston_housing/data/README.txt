Put boston.csv in this folder.
Columns: CRIM, ZN, INDUS, CHAS, NOX, RM, AGE, DIS, RAD, TAX, PTRATIO, B, LSTAT, MEDV
If CSV is not found, all scripts will use synthetic demo data with the same schema.

Download from: https://www.kaggle.com/datasets/vikrishnan/boston-house-prices
Note: The B column (based on racial composition) is controversial.
